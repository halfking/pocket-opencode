# 系统总览 v3：完整架构图（审计修正版）

> **状态**：目标架构，未实现。RedClaw 不能直接替代 OpenCode runtime；默认保留 OpenCode session/runtime，并通过 ZAG 做控制面适配。

---

## 1. 一句话设计哲学

> **OpenPocket（移动控制台）+ RedClaw（PC 桌面执行）+ ZAgentGateway（中介）+ acc-go（任务编排）+ Memora（记忆）+ llm-gateway-go（LLM 路由）= 完整的"手机控制 PC 上的多 AI Agent 工作"系统。**

不替换现有服务；新增一个规划中的独立服务 `ZAgentGateway`。当前能力按证据等级区分，RedClaw Gateway、generic connectors、ACC worker 闭环和 IDE 控制尚未由本仓库验证。

## 4. 端到端数据流

### 4.1 用户故事 1：手机发起"修复 OAuth bug"

```
[OpenPocket Mobile]
  │ 用户输入 "修复 OAuth bug"
  │ POST /api/fleet/intent
  ▼
[pocketd :8088]
  │ fleetbridge.intent.go
  │ → POST acc-go /api/v2/canonical/tasks
  ▼
[acc-go :4101]
  │ orchestrator.HeuristicTriage
  │ taskdecompose.ai_decompose (调 llm-gateway-go → DeepSeek)
  │ assign-subtasks (3 个子任务)
  │ orchestration v3 → 选 worker
  ▼
[ZAgentGateway :9100]
  │ POST /api/v1/tasks (acc-go → ZAG)
  │ ZAG 转发到 RedClaw platform-go
  │ POST /api/v1/tasks (ZAG → RedClaw)
  ▼
[RedClaw platform-go :8090 orchestrator]
  │ 入队 task
  │ 调 agentcontainer invoke
  ▼
[RedClaw agentcontainer :8091]
  │ 创建 workspace, 拉代码
  │ 启动 OpenClaw CLI 子进程
  │ OpenClaw 通过 llm-gateway-go 调 DeepSeek
  ▼
[OpenClaw CLI on user's Mac]
  │ 通过已验证 IDE adapter 调 zcode / vscode 插件（planned）
  │ 修改文件 / 应用 diff
  │ git commit + 想 push 时触发 permission
  ▼
[RedClaw SSE → ZAG → acc-go SSE → pocketd WS Bridge → Mobile WS Hub]
  │ OpenPocket Live View 实时显示
  ▼
[用户点击 "Allow git push" → permission 流转 → RedClaw push 完成]
  ▼
[OpenPocket 显示 "PR #145 opened"]
```

### 4.2 用户故事 2：手机查看 PC 状态

```
[OpenPocket Mobile → /fleet/pods]
  │
  │ GET /api/fleet/pods
  ▼
[pocketd fleetbridge.pod.go → ZAG client]
  │
  │ GET ZAG /api/v1/pods
  ▼
[ZAgentGateway]
  │ 1. 调 RedClaw platform-go GET /api/v1/devices
  │ 2. 合并 acc-go GET /api/v2/devices
  │ 3. 加 IDE 状态（通过实际 adapter；当前 generic connector 未验证）
  │ 4. 加 OpenClaw 状态
  │ 5. 落本地 DB
  │ 6. 返回统一格式 Pod[]
  ▼
[OpenPocket Mobile]
  │ 显示：
  │   Pod: mbp16-居家
  │   🟢 3 Agents / 2 Builds
  │   🟢 ZCode v1.2.3 / ⚪ VS Code / 🟢 Cursor
  │   🟢 OpenClaw v1.2.3
```

### 4.3 用户故事 3：通过 MCP（Cursor）调用 ZAG

```
[Cursor (或其他 MCP client)]
  │ MCP tools/list
  ▼
[ZAG /mcp]
  │ 返回 zag_* tools
  │ Cursor 用户在 Composer 输入 "查看我的 Mac 上 OpenClaw 状态"
  ▼
[Cursor → ZAG /mcp tools/call]
  │ { name: "zag_list_agents", args: { fleetId: "ws_001" } }
  ▼
[ZAG]
  │ 调 RedClaw platform-go 拉 device / agent 列表
  │ 返回 JSON
  ▼
[Cursor 显示 "你 Mac 上有 3 个 OpenClaw Agent，2 个正在跑任务..."]
```

## 5. 与 v1 / v2 的关键差异

| 维度 | v1 | v2 | **v3** |
|---|---|---|---|
| 核心抽象 | 自建 Chief + Bridge + Harness | 复用 acc-go + Memora + llm-gateway-go | **新增 ZAgentGateway；复用 acc-go + Memora + llm-gateway-go + RedClaw platform-go** |
| 算力舱 | pocketd-executor (自建) | acc-go Worker | **ZAgentGateway + RedClaw platform-go + OpenClaw CLI** |
| **本地 IDE 控制** | ❌ | ❌ | **planned：独立 adapter + connector contract** |
| **PC Agent 监控** | ❌ | ❌ | **planned：只读聚合需真实合同验证** |
| **PC Agent 控制** | ❌ | ❌ | **planned：独立审批签名 + durable state** |
| 移动端 | pocketd | pocketd | **pocketd + fleetbridge + zag client** |
| 多服务协同 | 单服务 | 单服务 | **多服务协同（明确边界）** |

## 6. 关键集成点

### 6.1 pocketd ↔ ZAG

```http
# pocketd fleetbridge 通过 zag client 调用
GET    /api/fleet/pods                     → ZAG GET    /api/v1/pods
GET    /api/fleet/pods/:id                 → ZAG GET    /api/v1/pods/:id
POST   /api/fleet/pods/:id/control         → ZAG POST   /api/v1/pods/:id/control

GET    /api/fleet/agents                   → ZAG GET    /api/v1/agents
GET    /api/fleet/agents/:id              → ZAG GET    /api/v1/agents/:id

GET    /api/fleet/ide                      → ZAG GET    /api/v1/ide
GET    /api/fleet/ide/:name/status        → ZAG GET    /api/v1/ide/:name/status
POST   /api/fleet/ide/:name/command        → ZAG POST   /api/v1/ide/:name/command

GET    /api/fleet/ws                       → ZAG GET    /api/v1/ws
```

### 6.2 ZAG ↔ acc-go

```http
# ZAG 注册为 acc-go worker
POST   /api/v2/devices                     # ZAG → acc-go

# acc-go 派任务给 ZAG
POST   /api/v1/tasks                       # acc-go → ZAG

# ZAG 推事件给 acc-go (SSE-like)
POST   /api/v2/missions/{id}/events        # ZAG → acc-go (NDJSON)
```

### 6.3 ZAG ↔ RedClaw platform-go

```http
# mTLS + delegated token + 独立审批签名（目标）
GET    /api/v1/devices                     # ZAG → RedClaw
POST   /api/v1/tasks                       # ZAG → RedClaw
GET    /api/v1/tasks/:id                   # ZAG → RedClaw
GET    /api/v1/tasks/:id/events            # ZAG → RedClaw (SSE)

POST   /api/v1/invoke                      # ZAG → RedClaw agentcontainer
GET    /api/v1/skills                      # ZAG → RedClaw

POST   /api/v1/connectors                  # 目标接口；当前 generic connector 未证明 IDE 已接通
POST   /api/v1/connections/:id/execute     # ZAG → RedClaw (IDE 命令)

POST   /api/v1/control                     # ZAG → RedClaw (Ed25519 双签)
POST   /api/v1/control/:id/signature
POST   /api/v1/control/:id/execute
```

### 6.4 ZAG ↔ llm-gateway-go（兜底）

```http
POST   /v1/chat/completions                # ZAG → llm-gateway-go（仅兜底）
```

### 6.5 ZAG ↔ Memora

```http
POST   /api/v2/memories                    # ZAG 写事件日志 / Charter / Skill / Memory
GET    /api/v2/memories?namespace=...
POST   /api/v2/memories/search
```

## 8. 安全边界

| 服务 | 鉴权 | 多租户 |
|---|---|---|
| **OpenPocket Mobile → pocketd** | JWT (POCKET_JWT_SECRET) | claims.WorkspaceID |
| **pocketd → ZAG** | JWT + mTLS | X-Tenant-ID + X-User-ID 透传 |
| **pocketd → acc-go** | delegated token + mTLS（目标） | verified token claims |
| **pocketd → Memora** | JWT + X-Tenant-ID | claims.WorkspaceID |
| **pocketd → llm-gateway-go** | API Key | per-tenant |
| **ZAG → RedClaw platform-go** | mTLS + delegated token + 独立审批签名 | verified token claims |
| **ZAG → acc-go** | delegated token + mTLS（目标） | verified token claims |
| **ZAG → Memora** | JWT + X-Tenant-ID | X-Tenant-ID |
| **ZAG → llm-gateway-go** | API Key | per-tenant |
| **RedClaw → OpenClaw CLI** | Local socket / mTLS | Tenant ID |
| **RedClaw → IDE 插件** | Connector AuthMode (mTLS / OAuth2 / API key) | per-tenant |
