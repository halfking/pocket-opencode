## 5. 数据流（v3 三大场景）

### 5.1 场景 A：手机发指令 → PC OpenClaw 跑任务

```
[OpenPocket Mobile]
  │ POST /api/fleet/intent
  ▼
[pocketd :8088]
  │ fleetbridge.intent.go
  │ → POST acc-go /api/v2/canonical/tasks
  ▼
[acc-go :4101]
  │ taskdecompose (LLM 拆分)
  │ orchestration v3
  │ → 选 worker = ZAG
  │ POST ZAG /api/v1/tasks
  ▼
[ZAgentGateway :9100]
  │ 收到任务
  │ POST RedClaw platform-go /api/v1/tasks
  ▼
[RedClaw platform-go orchestrator]
  │ 入队 + agentcontainer invoke
  ▼
[OpenClaw CLI]
  │ 调 llm-gateway-go → DeepSeek
  │ 通过 RedClaw connectors 调 IDE
  ▼
[RedClaw SSE 流]
  ▼
[ZAG 翻译事件 + 落 Memora + 推 acc-go SSE + 推 WS Hub]
  ▼
[OpenPocket Mobile Live View]
```

### 5.2 场景 B：手机查看 PC 上 IDE / OpenClaw 状态

```
[OpenPocket Mobile /fleet/pods]
  │ GET /api/fleet/pods
  ▼
[pocketd fleetbridge.pod.go]
  │ GET ZAG /api/v1/pods
  ▼
[ZAG]
  │ 并行调：
  │  - RedClaw platform-go GET /api/v1/devices (OpenClaw devices)
  │  - RedClaw connectors GET /api/v1/connections/ide_zcode/status
  │  - RedClaw connectors GET /api/v1/connections/ide_vscode/status
  │  - RedClaw connectors GET /api/v1/connections/ide_cursor/status
  │  - RedClaw connectors GET /api/v1/connections/ide_opencode/status
  │ 合并 + 落本地 DB
  │ 返回统一格式
  ▼
[OpenPocket Mobile 显示]
```

### 5.3 场景 C：Cursor 通过 MCP 调用 ZAG 控制 PC

```
[Cursor (MCP client)]
  │ MCP tools/call: zag_get_ide_status { name: "zcode" }
  ▼
[ZAG /mcp]
  │ → RedClaw connectors GET /api/v1/connections/ide_zcode/status
  ▼
[ZAG 返回 MCP response]
  ▼
[Cursor 显示 "你 Mac 上的 ZCode v1.2.3 在 /Users/me/myapp 工作区"]
```

  "code": 5020,
  "error": {
    "code": "redclaw.unavailable",

## 8. 与 v2 的差异

v2 数据流：mobile → pocketd → acc-go → llm-gateway-go → Provider
v3 数据流：mobile → pocketd → acc-go → **ZAG → RedClaw platform-go → OpenClaw CLI / IDE**

主要变化：

- 引入 ZAG 作为中介；
- RedClaw platform-go 成为执行层（替代了 v2 中"acc-go Worker = 自建 Harness"）；
- IDE 控制、OpenClaw CLI 调用、本地 device 状态聚合全部经 ZAG；
- acc-go 仍然是 Chief / orchestrator，但 worker 现在是 ZAG 而非自建 harness。

---

## 9. 一句话总结

**v3 的数据流 = OpenPocket (mobile) → pocketd (BFF) → acc-go (Chief) → ZAgentGateway (中介) → RedClaw platform-go (PC enterprise) → OpenClaw CLI (实际执行) + 本地 IDE 插件 (代码编辑) → 事件回流到手机 Live View。**
