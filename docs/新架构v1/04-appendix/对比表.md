## 2. 我们最不应该错过的能力（来自 todos.dev）

| 能力 | 为什么重要 | 实现路径 |
|---|---|---|
| Chief + Charter | 用户信任感 + 可定制 | M2 |
| tds CLI（executor） | "数据不出域"是杀手锏 | M0 起就开始 |
| 双开关权限 | 安全默认值 | M2 |
| 透明 cost | 用户最关心 | M2 |
| 排队而非 fail-fast | 体验 | M3 |

## 3. 我们最不应该错过的能力（来自 Cursor iOS）

| 能力 | 为什么重要 | 实现路径 |
|---|---|---|
| Live Activity / Dynamic Island | iOS 上极强 affordance | M4 |
| Remote Control（循环云跑，工具本地） | 用户保留私域仓库 | M5+ |
| PR Diff mobile viewer | 用户在手机上 review | M1 |

## 4. 我们对 todos.dev 的超越

| 维度 | 我们怎么做 |
|---|---|
| **多 LLM 默认一等公民** | DeepSeek 一等公民；OpenAI / Anthropic / 本地 Ollama 都是 1st-class |
| **真正的 Live 流** | WS + 真正的 streaming delta，不是轮询 |
| **执行机多样性** | 自有 / 平台 / 边缘盒 / 云 GPU 同一接口 |
| **统一 mobile 体验** | PWA + Capacitor 双端，覆盖 todos.dev 的 PWA + Cursor 的 iOS |
| **既有 opencode-pocket 用户资产** | Instance / Session / Email / Notes 不丢 |
| **kxmemory / llm-gateway 集成** | 跨 Agent 共享 context，省 token |

## 5. 我们对 Cursor iOS 的超越

| 维度 | 我们怎么做 |
|---|---|
| **Android** | 一开始就 PWA，Capacitor 包装双端 |
| **Self-host** | 用户可完全私有部署 + 自有 Pod |
| **多 LLM** | 不绑定 Anthropic；DeepSeek / Qwen / GLM 都行 |
| **跨多 Pod / 多仓** | Cursor Cloud Agent 是 1 仓 1 跑；我们是 1 仓多跑 + 多仓多跑 |

## 6. 我们的"底线"（v1.0 必须有）

- ✅ Chief 能基于 LLM 智能拆分；
- ✅ 至少 1 种 Pi Agent Harness 跑通；
- ✅ 至少 1 个 Pod 类型支持（用户自有）；
- ✅ PWA + Capacitor 双端基础体验；
- ✅ Permission request 移动审批；
- ✅ Live streaming 显示 build 进度；
- ✅ Cost 用量可见；
- ✅ DeepSeek 一等公民（默认 Provider）。
