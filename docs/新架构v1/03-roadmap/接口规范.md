# 接口规范 v3：pocketd fleetbridge + ZAgentGateway

> PocketFleet v3 的接口分两层：
> 1. **pocketd 对 mobile 暴露**：所有 `/api/fleet/*`，JWT 鉴权；
> 2. **ZAgentGateway（规划中）对 pocketd / acc-go / RedClaw 暴露**：`/api/v1/*`，短期 delegated token + mTLS + 对象级授权。
>
> pocketd fleetbridge 做受控适配 + SSE/WS 桥接；ZAG 做 RedClaw task/run 与 OpenCode session 的映射。当前这些 `/api/fleet/*` 和 ZAG `/api/v1/*` 均为 planned contract，不能视为已实现。

---

## 1. 协议栈总览

```
Mobile / PWA / Capacitor
   │ HTTPS / WSS
   │ JWT (POCKET_JWT_SECRET)
   ▼
pocketd (:8088)
   │ fleetbridge + zag client
   ├─► acc-go (:4101)         REST + SSE + MCP + A2A
   ├─► Memora (:8080)         REST
   ├─► llm-gateway-go (:8781) REST (已存在客户端；Provider fallback 受租户策略约束)
   └─► ZAgentGateway (:9100)  REST + SSE + WebSocket + MCP
                                  │
                                  │ mTLS + delegated token + 独立审批签名
                                  ▼
                          RedClaw platform-go (:8080-8093)
                                  │
                                  ▼
                          OpenClaw CLI + 本地 IDE 插件
```

## 6. 安全与一致性契约（M0 必须冻结）

### 6.1 身份

服务间 token 必须包含 `iss`、`aud`、`sub`、`tenant_id`、`actor_id`、`actor_type`、`scope`、`jti`、`iat`、`exp`。服务端验证签名、受众、过期、jti 和对象 tenant。请求体或 header 中的 `tenantId/userId/fleetId` 与 token 不一致时拒绝。

### 6.2 写请求

所有创建、控制、审批、IDE 写命令要求：

- `Idempotency-Key`；
- `X-Request-Id` 和 `traceparent`；
- `operation_id`；
- 签名覆盖 method、normalized path、body hash、tenant、subject、timestamp、nonce、key_id；
- nonce/jti 持久化防重放。

未知超时必须先查询和 reconciliation，不能直接 retry 可能产生副作用的操作。

### 6.3 事件

每个 SSE/WS 事件必须包含：

```json
{
  "event_id": "uuid",
  "sequence": 7,
  "schema_version": 1,
  "tenant_id": "from-verified-claims",
  "aggregate_id": "task-or-session-id",
  "aggregate_version": 3,
  "operation_id": "uuid",
  "type": "task.update",
  "data": {}
}
```

必须定义 Last-Event-ID 补偿、去重、乱序、背压、最大消息和断线重认证。

### 6.4 OpenCode 兼容边界

若目标是让现有 OpenCode client 连接 RedClaw，必须另行实现并验证：

```text
/session
/session/:id/message（parts）
/event（EventV2/SSE）
/permission、/question
/pty（WebSocket）
```

当前 RedClaw `/api/v1/tasks`、`/api/v1/sessions`、`/api/v2/tasks` 只作为控制面输入，不是 OpenCode-compatible API。

## 7. 与现有 pocketd 协议兼容性

### 7.1 不破坏现有 API

`/api/fleet/*` 是新前缀；既有 `/api/agent/*`、`/api/email/*`、`/api/notes/*`、`/api/opencode/*` 不动。

### 7.2 复用现有 WS Hub

`/api/fleet/ws` 走 `internal/websocket/hub.go` 现有 Hub；fleetbridge 把 acc-go SSE + ZAG SSE 转换为 Hub 事件格式。

### 7.3 复用现有 Audit

所有 fleetbridge / zag client 的 HTTP 请求都被 `internal/redclaw/audit.go` 记录。

### 7.4 复用现有 Notification

Permission request → push notification 走 `internal/notification/`。

### 7.5 复用现有 STT

Voice input → 现有 `internal/stt/` 模块。

## 10. 与 v2 接口规范的差异

| 维度 | v2 | v3 |
|---|---|---|
| Intent 处理 | acc-go Chief | **acc-go Chief → ZAG → RedClaw OpenClaw** |
| 任务管理 | acc-go 透传 | **ZAG 透传**（pocketd → ZAG → RedClaw） |
| Permission | acc-go taskgate | **ZAG → RedClaw taskgate** |
| SSE event schema | 11 类（acc-go）| **+ 8 类（ZAG 新增：pod.status / agent.status / session.* / ide.status / control.signal）** |
| LLM 调用 | llm-gateway-go | **RedClaw Gateway (主) + llm-gateway-go (兜底)** |
| Pod / Agent / IDE API | ❌ | **ZAG 暴露**（PC device / OpenClaw / ZCode / VS Code / Cursor / OpenCode） |
| MCP | acc-go 41 tools | **acc-go 41 tools + ZAG zag_* tools（双 MCP）** |
| 鉴权 | JWT / HMAC | **JWT + delegated token + mTLS + 独立审批签名；禁止裸 header 授权** |
