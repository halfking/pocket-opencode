### 5.4 关键约束

1. **多租户强制**：`tenant.From(ctx)` 在所有 DB 操作前必须有；自定义 golangci-lint rule 检查。
2. **Ed25519 双签**：Rollback / Upgrade / Terminate 必须两个 admin 签名才能执行。
3. **Plan A / Plan E 权限模型**：Plan A = 默认；Plan E = 强制审批。
4. **Stable Error Envelope**：`{"error":{"code":"...","message":"..."}}`
5. **WS 事件总线**：所有 task / session / control event 通过统一 Hub 推送。

### 5.5 OpenClaw CLI（被包装的 runtime）

- npm 包，全局安装 `openclaw`；
- 用户 Mac 上的桌面 AI 助手；
- 支持 Skills 子进程调用；
- 支持 file_read / file_write / shell_run / git_* / web_* 工具；
- 与 OpenClaw Server 通过 WebSocket 通信。

### 5.6 Connectors 实际能力（关键）

RedClaw 的 Connectors 模块定义了外部集成的标准接口，包括：

- **Inbound**：Cursor 类型（offset / timestamp / webhook）、批量 ingest、dedup；
- **Outbound**：执行外部命令、Idempotency Key、Policy Snapshot、Assurance Permit；
- **Side Effect Level**：操作的危险等级（影响是否需要审批）。

**这是 IDE 控制的天然接口** —— ZAgentGateway 通过 Connectors 模式接入 ZCode / VS Code / Cursor / OpenCode 等 IDE。

## 6. ZAgentGateway 引入的合理性（v3 vs v2）

| 需求 | v2 方案 | v3 方案（更合理）|
|---|---|---|
| 在手机上查看 PC 上 OpenClaw 的运行状态 | ❌ v2 没考虑 OpenClaw | ✅ ZAgentGateway 拉 RedClaw device/agent |
| 在手机上控制 PC 上的 OpenClaw | ❌ v2 算力舱是 acc-go worker（没 OpenClaw） | ✅ ZAgentGateway 转发到 RedClaw platform-go |
| 在手机上控制 PC 上的 IDE（zcode / vscode / cursor） | ❌ v2 完全没考虑 | planned：需要 ZAG + 实际 IDE adapter + RedClaw connector contract |
| 让 RedClaw 桌面 IM 消息触发的 Agent 任务同步给手机 | ❌ v2 没考虑 | ✅ ZAgentGateway 通过 RedClaw SSE → OpenPocket WS |
| 让 OpenClaw 桌面端的"审批中心"通知到手机 | ❌ v2 没考虑 | ✅ ZAgentGateway 转发 RedClaw authagent |
| 让 OpenPocket 的应用后端用 RedClaw 的 LLM 能力 | ⚠️ v2 走 redclaw echo stub | ✅ ZAgentGateway 调 RedClaw gateway |

**ZAgentGateway 是 OpenPocket（移动）+ RedClaw（PC）+ acc-go（编排）三者协同的关键中介**。

## 7. ZAgentGateway 的关键设计决策

| 决策 | 理由 |
|---|---|
| **独立 Go 服务** | 单一职责；多副本；与 RedClaw platform-go 同语言 |
| **端口 9100** | 避开 monorepo 已有端口（8088 / 8781 / 4101 / 8080 / 8090-8093） |
| **不替代 RedClaw platform-go** | RedClaw 是企业平台（带 SSO / Ed25519 双签）；ZAgentGateway 是"控制中心中介" |
| **不直接连 Provider** | 所有 LLM 走 RedClaw gateway 或 llm-gateway-go |
| **暴露 MCP** | 让 Cursor / Claude Code / acc-go 等 MCP 客户端调用 |
| **复用 Memora 做记忆** | Charter / Skill / 事件日志 落 Memora |
| **复用 acc-go 的 tenant.From** | 多租户 L1 invariant |
| **Ed25519 双签控制信号** | Rollback / Upgrade / Terminate 需要两个 admin 签 |

## 9. 与 acc-go / Memora / llm-gateway-go / pocketd / RedClaw 的关系

```
┌──────────┐         ┌──────────┐         ┌──────────────┐
│ OpenPocket│ ──►──── │ acc-go   │ ──►──── │ ZAgentGateway│ ──►──── RedClaw platform-go
│ (pocketd) │         │ (Chief)  │         │ (中介)        │            (orchestrator + agentcontainer)
└────┬─────┘         └────┬─────┘         └──────┬───────┘            └──────────┬──────────┘
     │                    │                      │                              │
     │                    ▼                      ▼                              ▼
     │              ┌──────────┐         ┌──────────────┐              ┌──────────────┐
     │              │ llm-gw-go│         │ RedClaw      │              │ OpenClaw CLI │
     │              │ (LLM)    │         │ platform-go  │              │ (PC runtime) │
     │              └──────────┘         │ (直接调 / 兼容)│              └──────────────┘
     │                                   └──────┬───────┘
     ▼                                          │
┌──────────┐         ┌──────────┐               ▼
│ Memora   │ ◄────────┤ ZAG      │ ◄──────── ┌──────────────┐
│ (Charter,│          │ 直接写    │           │ RedClaw Gateway│
│ Skill,   │          │ events   │           │ :8092 (LLM代理)│
│ Memory)  │          └──────────┘           └──────────────┘
└──────────┘
```

- **acc-go → ZAgentGateway**：acc-go 把 ZAgentGateway 注册为一个 worker / device；任务通过 acc-go 派发到 ZAgentGateway。
- **ZAgentGateway → RedClaw platform-go**：ZAgentGateway 调 RedClaw 的 orchestrator / agentcontainer / connectors；用 Ed25519 双签做控制信号。
- **ZAgentGateway → Memora**：事件日志、Charter、Skill、Memory 落 Memora。
- **OpenPocket → ZAgentGateway**：pocketd 调 ZAgentGateway 拉 PC Agent / Pod / Session / IDE 状态，提交任务，订阅事件。
- **ZAgentGateway → RedClaw Gateway (LLM)**：需要 LLM 时走 RedClaw Gateway。
- **ZAgentGateway → llm-gateway-go (直连)**：兜底或显式路由。
