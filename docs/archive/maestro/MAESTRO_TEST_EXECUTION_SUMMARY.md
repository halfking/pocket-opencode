## 🚀 快速启动（5 分钟上手）

### 第一步：配置环境

```bash
# 1. 设置环境变量
export POCKET_MASTER="12345678"
export POCKET_DEV_PASS="<DEV-PASS-PREFIX>…<masked>"

# 2. 启动后端服务（在另一个终端）
cd backend
./pocketd

# 3. 配置端口转发
adb reverse tcp:18099 tcp:8088

# 4. 验证环境
./scripts/verify-maestro-env.sh
```

### 第二步：运行测试

```bash
# 方案 A: 运行冒烟测试（推荐首次）
./scripts/run-maestro-suite.sh smoke

# 方案 B: 运行完整测试
./scripts/run-maestro-suite.sh master

# 方案 C: 运行回归测试
./scripts/run-maestro-suite.sh regression

# 方案 D: 运行所有测试
./scripts/run-maestro-suite.sh all
```

### 第三步：查看结果

```bash
# 查看测试报告
cat test-reports/test-summary-*.txt

# 查看截图
open logs/maestro/

# 查看 JUnit 报告
open test-reports/*.xml
```

## 🚧 已知限制

### 当前限制

1. **语言支持**: 中英文并列选择器，其他语言未测试
2. **设备覆盖**: 仅在 Android 设备测试，iOS/HarmonyOS 未覆盖
3. **网络依赖**: 需要后端服务可访问
4. **状态管理**: 部分测试依赖应用初始状态
5. **异步操作**: 长时间操作（如转写）未充分测试

### 不支持场景

- ❌ 离线模式测试
- ❌ 多设备同步测试
- ❌ 性能压测
- ❌ 后台服务测试
- ❌ 推送通知测试
- ❌ 深度链接测试
