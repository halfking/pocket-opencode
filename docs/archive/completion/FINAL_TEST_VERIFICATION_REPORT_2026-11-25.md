### 技术限制分析

**根本原因**: 设备安全策略阻止第三方应用安装

Maestro需要在目标设备上安装驱动应用（`maestro.app.server`）来执行UI自动化操作。在当前测试设备上，安装被用户限制策略阻止：

```
Failure [INSTALL_FAILED_USER_RESTRICTED: Install canceled by user]
```

**可能的解决方案**:
1. 在设备设置中允许第三方应用安装
2. 使用开发者模式解除安装限制
3. 使用不同的测试设备或模拟器
4. 使用替代测试方法（ADB UI Automator）
