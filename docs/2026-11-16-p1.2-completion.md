## ✨ 功能特性

### 1. 版本对比显示
```
┌─────────────────┐       ┌─────────────────┐
│  📱 本地版本     │  VS   │  ☁️ 远程版本    │
│  2026-11-16     │       │  2026-11-16     │
│  14:30          │       │  12:00          │
├─────────────────┤       ├─────────────────┤
│                 │       │                 │
│  [内容预览]     │       │  [内容预览]     │
│                 │       │                 │
└─────────────────┘       └─────────────────┘
```

**特点**:
- 并排显示本地和远程版本
- 显示最后更新时间
- 字符数统计
- 颜色区分（本地=蓝，远程=绿）

### 2. 两种视图模式
- **Markdown 预览**: 渲染后的效果，便于阅读
- **原始文本**: 查看实际内容，便于比对

一键切换按钮

### 3. 三种解决方式

#### 方式 1: 接受本地版本
- 保留本地编辑内容
- 覆盖远程版本
- 一键操作

#### 方式 2: 接受远程版本
- 使用 memora 云端版本
- 丢弃本地修改
- 一键操作

#### 方式 3: 手动合并
- 进入编辑模式
- 在文本框中编辑合并结果
- 支持自由编辑
- 应用合并按钮

- ✅ 模态框遮罩，点击关闭
- ✅ ESC 键关闭（可扩展）

## 🔧 技术实现

### 依赖
```typescript
import { useSyncStateStore } from '@/stores/syncState'
import { marked } from 'marked'
```

### Props 接口
```typescript
interface Props {
  show: boolean              // 显示/隐藏
  noteId: string            // 笔记 ID
  localVersion: Version     // 本地版本
  remoteVersion: Version    // 远程版本
}

interface Version {
  content: string
  updatedAt: number
}
```

### Emits 事件
```typescript
emit('close')      // 关闭对话框
emit('resolved')   // 冲突已解决
```

### 核心方法
```typescript
handleResolve(resolution: 'local' | 'remote')
  → 调用 syncStateStore.resolveConflict()
  → 调用后端 API: POST /api/sync/resolve/:noteId

handleMerge()
  → 应用手动合并的内容
  → 需要更新笔记内容（TODO: 集成 notes API）

renderMarkdown(content)
  → 使用 marked 库渲染 Markdown
  → 错误处理，降级显示原文
```

## 📋 使用示例

### 在 NoteEditor 中集成

```vue
<template>
  <div class="note-editor">
    <!-- 同步状态指示器 -->
    <SyncStatusIndicator 
      :noteId="note.id"
      @conflict-detected="showConflictDialog = true"
    />

    <!-- 冲突解决对话框 -->
    <ConflictResolver
      :show="showConflictDialog"
      :noteId="note.id"
      :localVersion="localVersion"
      :remoteVersion="remoteVersion"
      @close="showConflictDialog = false"
      @resolved="handleConflictResolved"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import SyncStatusIndicator from '@/components/knowledge/SyncStatusIndicator.vue'
import ConflictResolver from '@/components/knowledge/ConflictResolver.vue'

const showConflictDialog = ref(false)
const localVersion = ref({
  content: 'Local note content...',
  updatedAt: Date.now()
})
const remoteVersion = ref({
  content: 'Remote note content...',
  updatedAt: Date.now() - 3600000
})

const handleConflictResolved = () => {
  showConflictDialog.value = false
  // 刷新笔记内容
  refreshNote()
}
</script>
```
