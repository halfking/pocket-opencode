# 🎯 应用安装指南

**APK已传输到手机！**

## 📱 在手机上的安装步骤

### 步骤1: 打开文件管理器
- 找到手机的"文件管理"或"我的文件"应用
- 点击打开

### 步骤2: 进入下载文件夹
- 找到"下载"或"Download"文件夹
- 点击进入

### 步骤3: 找到APK文件
- 找到 **opencode-pocket.apk** (24 MB)
- 点击这个文件

### 步骤4: 允许未知来源安装
如果弹出"为了安全，您的手机不允许安装未知来源的应用"：
1. 点击"设置"
2. 找到"允许安装未知应用"
3. 找到"文件管理器"或当前使用的应用
4. 打开"允许来自此来源"的开关
5. 返回并重新点击APK

### 步骤5: 确认安装
1. 点击"安装"按钮
2. 等待安装完成（几秒钟）
3. 看到"应用已安装"
4. 点击"打开"或"完成"
