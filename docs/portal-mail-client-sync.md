# 邮件门户客户端同步

本切片同步邮件账户元数据与邮件摘要。收件箱中的「跨端邮件摘要」是独立读模型：远端账户不会创建或启用本地收信账户，远端摘要不猜测 `account_id`，远端墓碑不删除本机正文、附件、译文或凭据。

## 来源与归属

- 账户只投影 `address/display_name/last_sync_at`；摘要只投影 `from/subject/snippet/received_at`。摘要优先使用 AI 摘要，未提供时使用原有 snippet。
- 新的本机账户、通过受保护来源首次写入的账户与摘要，以及已管理记录的明确本机修改，在源行修改的同一 SQLite 事务写入加密投影和不可变 outbox。账户删除与已管理子摘要的墓碑同事务提交。
- 所有操作在第一个 await 前捕获原 owner、操作租约、修改时间和当时已知的邮件 reset epoch。重试保留原操作 ID、时间、内容与 epoch。
- 没有投影的历史本地行不扫描、不认领。修改历史行也不会自动建立跨端归属。未知 source 修改时间会保留为 blocked 操作；后续拉取不会补当前 epoch 或下载时间。
- 账户镜像不能越过已发起的本地账户修改；源写入与投影在 SQL 中使用版本条件，旧提交不能覆盖更新的投影。
- 账户删除在同一事务中断言父源行、子邮件数量及每行完整源快照未变化，再执行级联删除与墓碑。期间新增或修改子邮件（包括无版本的已读等字段）会使整批回滚并提示重试，避免云端孤立摘要或删除刚发生的本地修改。
- 本机收信配置与独立门户元数据分别编辑。仅修改启用状态、IMAP 等私有设置不生成门户操作；账户镜像也只合并相对源行发生变化的共享字段。明确修改显示名或地址时，保留门户其余字段；收信完成仅更新 `last_sync_at`。

## 同步与界面

通用 record 同步层提供逐项确认、保留精度的 LWW、增量游标、墓碑、可信工作区断言和 reset epoch。邮件工厂是 `portalEmailRuntime`，由应用启动接线激活，设置页使用共用模块状态通知。

收件箱元数据区可编辑或删除独立投影。该操作不会修改本机收信配置或原始邮件。账号、工作区或激活代次变化时立即清空元数据、编辑草稿和选择状态；远端更新和删除会刷新列表。列表加载序号与 owner 代次分离，保存或删除触发的队列刷新不影响操作结束和编辑器关闭。

旧 pocketd 的无版本删除与分类推送仍无法提供完整 LWW：本地结果保留，同时阻止旧快照上传并显示待处理状态。完整自动收敛需要来源协议提供可信的原始修改版本；本切片不会伪造该版本。用户可在独立元数据区发起明确的新修改或删除。旧 `kind=item` 邮件形状不进行不明确的自动映射。

## 验证

- 真实 LocalDB/SQLite：源和队列原子回滚、不可变操作、历史不认领、未知时间阻塞、凭据与正文保留、原始 owner、账户级联墓碑、源镜像与本地编辑并发、加密和 reset 后旧队列保留。
- 真实 Vue 元数据组件与 SQLite 浏览器回归：编辑、账号/工作区切换、远端更新和墓碑，确认原始正文及账户保留。
- browser-use 使用同一隔离夹具进行了实际点击与输入。认证、网络传输和原生平台是明确的夹具边界；这不是目标部署或真机端到端验收。
- 邮件、API、App 及列表缓存相关全量回归、TypeScript 和生产构建通过；私有真实邮件语料诊断在未提供语料时保持条件跳过。

## 共享层依赖

邮件专有代码依赖会议同步任务提供的 `record-{contract,tables,epoch,store,engine,storage,runtime}.ts`、模块化 epochs、transport 和 reset-store。共享层唯一来源为会议任务；本工作树内复制的共享文件仅用于验证，不属于邮件提交范围。
