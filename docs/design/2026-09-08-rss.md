## 2. 数据模型（已落地）

rss schema 已经在 `internal/rss/store.go::migrate(ctx)` 中以 `CREATE TABLE IF NOT EXISTS` 形式自管（与 email / notes / scheduledtask / meeting 同模式）。

```
rss_sources     (id PK, user_id, workspace_id, url UNIQUE per (user,workspace),
                 title, description, site_url, language,
                 etag, last_modified, status, enabled, error,
                 fetch_interval, next_fetch_at, last_fetched_at,
                 created_at, updated_at)
rss_items       (id PK, source_id FK CASCADE, user_id, workspace_id,
                 guid, hash, url, title, author, summary, content,
                 language, categories JSONB,
                 published_at, updated_at, fetched_at,
                 relevance, match_reasons JSONB, status,
                 UNIQUE(source_id, hash))
rss_filter_rules (id PK, user_id, workspace_id, name, enabled,
                  include_keywords JSONB, exclude_keywords JSONB,
                  languages JSONB, since_at, until_at, min_relevance,
                  created_at, updated_at)
rss_drafts      (id PK, item_id FK CASCADE, user_id, workspace_id,
                  text, status, created_at, updated_at,
                  UNIQUE(user_id, workspace_id, item_id))
rss_publish_attempts (id PK, draft_id FK CASCADE, item_id,
                      user_id, workspace_id, platform, remote_id,
                      status, error, attempted_at, created_at)
```

索引：
- `idx_rss_sources_due(user_id, workspace_id, enabled, next_fetch_at)` — scheduler 抢占
- `idx_rss_items_scope_date(user_id, workspace_id, published_at DESC)` — 信息流列表
- `idx_rss_items_source(source_id, published_at DESC)` — 单源详情
- `idx_rss_rules_scope(user_id, workspace_id, enabled)` — 过滤命中
- `idx_rss_drafts_scope / idx_rss_attempts_scope` — 草稿 / 发布日志列表

**保留**：drafts + publish_attempts 表已经写入 schema，但当前 handler 暂未开放 POST /api/rss/drafts 端点 — MVP 用 share-only 路径；保留 schema 是为了让"未来发微博草稿"这件事不需要 ALTER TABLE。

## 3. Scheduler 生命周期

参照 `emailScheduler` 模式（`cmd/pocketd/main.go`）：

```go
rssCtx, rssCancel := context.WithTimeout(context.Background(), 10*time.Second)
rs, err := rss.NewStore(rssCtx, pool)
rssCancel()
if err != nil { log.Fatalf("rss store: %v", err) }
rssStore = rs

// ...srv.New 之后...
if rssStore != nil && cfg.RSS.Enabled {
    srv.SetRSSStore(rssStore)
    fetcher := rss.NewFetcher(rssStore, nil)
    rssSched := rss.NewScheduler(rssStore, fetcher, rss.Scope{
        UserID:      "local",
        WorkspaceID: "default",
    })
    rssSched.SetInterval(cfg.RSS.FetchInterval)   // default 60s
    rssSched.SetMaxParallel(cfg.RSS.MaxConcurrency) // default 4
    srv.SetRSSScheduler(rssSched)
    rssSched.Start(context.Background())
    defer rssSched.Stop()
}
```

每 tick：扫 `next_fetch_at <= now` 的 enabled 源 → `SELECT … FOR UPDATE SKIP LOCKED LIMIT maxParallel` 抢占 → 逐源 `fetcher.RefreshSource`（带 ETag / Last-Modified / 304 / `Retry-After` 解析） → 解析 + 过滤 → `UpsertItemScoped`（`ON CONFLICT(source_id, hash) DO UPDATE`） → 推 WS hub。

scheduler 作用域用单租户默认 (`user=local, workspace=default`)。多租户场景下，每个 workspace 一个 scheduler；当前不需要。

## 4. 分享路径

| dest | 行为 |
|---|---|
| `wechat` | 朋友圈没有公开 API。前端 copy 文案到剪贴板，UI 提示"在微信里粘贴到朋友圈"；后端响应 hint：`wechat-moments-has-no-public-api` |
| `weibo` | 后端返回 `https://service.weibo.com/share/share.php?url=…&title=…` 深链；前端 `window.open` 触发微博分享面板（用户已登录微博则直接发布，未登录则登录流程） |
| `clipboard` | 后端返回 caption + 链接拼好的 copyText；前端 `navigator.clipboard.writeText` |
| `download` | 后端返回相对路径 `/api/rss/items/{id}/share-card`；前端 fetch 后用 `<a download>` 存盘 |

分享卡渲染（`internal/rss/sharecard.go`）：

- 1080 × 1350 PNG，纯 `image/draw` + `image/png`，**零外部依赖**
- 顶栏：accent 色条 + 源标题 + 源 URL
- 主区：标题（5×7 bitmap 字体，放大 6×）+ 摘要（最多 6 行）
- 底部：QR 占位（3 finder pattern + 中心方块）+ URL 文本 + @openpocket 水印

> 限制：MVP 用 5×7 ASCII bitmap，CJK 字符替换为 `?`。生产升级路径：嵌入 Noto Sans SC（pure Go 字体） + 真实 QR（go-qrcode 库）。

## 6. 错误码

| 状态 | 触发 |
|---|---|
| 401 | 未带 Bearer JWT / 过期 / claims 缺 user_id 或 workspace_id |
| 400 | body 不是合法 JSON / 必填字段缺失 / URL 通过 SSRF 校验 |
| 404 | source / item / filter id 不存在或不在该 scope |
| 405 | 方法不对（GET vs POST vs DELETE） |
| 501 | 微博 OAuth publish 未配置（保留字段，MVP 不实现） |
| 503 | store 未配置（PG 关闭或 RSS_ENABLED=false） |

## 9. 风险与已知限制

- 微信 / 微博官方 API 没有公开通路，MVP 用深链 + 剪贴板妥协
- ASCII bitmap 字体不支持中文标题（替换为 `?` 占位）
- QR 占位不是真实 QR（用户需手动复制链接）
- 单 scheduler 进程内并发上限由 `MaxConcurrency` 控制；分布式场景需要外部队列
- `internal/config/config.go` 工作副本存在 `WebAuthnRPDisplayName` 缺失字段等 pre-existing 编译错误（与 RSS 无关，不在本任务修复范围）
