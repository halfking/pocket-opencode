# OpenCode 任务管理系统 - 快速演示指南

## 🎬 演示准备

### 1. 确保环境准备就绪

```bash
# 检查 PostgreSQL 是否运行
psql -U pocket_user -d pocket_db -c "SELECT 1"

# 检查后端服务
curl http://localhost:9010/healthz

# 检查前端构建
cd frontend && npm run build
```

### 2. 初始化数据库（仅首次）

```bash
# 连接数据库
psql -U pocket_user -d pocket_db

# 检查表是否创建
\dt opencode_*

# 应该看到：
# opencode_sessions
# opencode_session_history
```

## 🐛 常见问题排查

### 问题 1: 看不到任何实例
**检查：**
```bash
# 检查 registry 中是否有实例
curl http://localhost:9010/api/instances

# 检查数据库
psql -U pocket_user -d pocket_db -c "SELECT * FROM opencode_instances;"
```

**解决：**
- 确保至少有一个 OpenCode 实例已注册
- 检查实例的 health 状态

### 问题 2: 会话列表为空
**检查：**
```bash
# 检查 OpenCode 是否运行
curl http://opencode-instance:3000/session

# 检查后端日志
tail -f /data/services/opencode-pocket/logs/pocket.log
```

**解决：**
- 确保 OpenCode 实例正在运行
- 检查网络连接
- 验证 API 地址配置

### 问题 3: 实时更新不工作
**检查：**
```bash
# 检查 WebSocket 连接
# 在浏览器开发者工具 Network 标签查看 WS 连接
```

**解决：**
- 检查 Nginx WebSocket 配置
- 确认防火墙规则
- 查看浏览器控制台错误

### 问题 4: 历史记录不显示
**检查：**
```bash
# 检查数据库
psql -U pocket_user -d pocket_db -c "SELECT COUNT(*) FROM opencode_session_history;"
```

**解决：**
- 历史记录需要时间积累
- 检查后端是否在记录事件
- 验证 history store 是否正常工作

## 📊 演示数据建议

### 理想演示场景
为了最佳演示效果，建议准备：

1. **3-5 个 OpenCode 实例**
   - 2-3 个在线
   - 1-2 个离线
   
2. **每个实例有 5-10 个会话**
   - 2-3 个进行中
   - 3-5 个空闲
   - 1-2 个已完成

3. **会话包含丰富的历史**
   - 多条消息
   - 文件编辑记录
   - 测试结果
   - 代码变更
