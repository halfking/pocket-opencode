单一入口封装 `vite build --mode <profile>` + `npx cap sync <platform>`，并在内置 sanity check 里 grep 确认 `VITE_API_BASE` 真的进入了 dist bundle——避免构建期变量没传导致静默打错包。

```bash
# 旧流程（手写）                     # 新流程
VITE_API_BASE=http://192.168.31.37:8088 \
  npm run build:fast && npx cap sync ios
                                       node scripts/build-mobile.mjs ios dev
VITE_API_BASE=http://10.0.2.2:8088 \
  npm run build:fast && npx cap sync android
                                       node scripts/build-mobile.mjs android dev
node scripts/build-mobile.mjs ios staging
VITE_API_BASE=https://prod.example.com \
  node scripts/build-mobile.mjs android prod
```

支持 `MOBILE_FAST=1` 跳过 vue-tsc，与历史 `build:fast` 等价。
