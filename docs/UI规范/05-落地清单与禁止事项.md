# 05 — 落地清单与禁止事项

> 现行约束。做完任一前端 UI 变更，按档位自检。

## 1. 新页面 / 改页面检查表

### 所有档

- [ ] 金额与权限字段政策与宽屏表一致
- [ ] 写操作有防重与既有确认
- [ ] **无新增断点魔法数**（见 [01](./01-原则与断点.md)）
- [ ] **无新增范围语法媒体查询**（必须传统 `min/max-width`）
- [ ] 媒体查询里出现的宽度值都在 SSOT 集合内（门禁会抓）
- [ ] 不顺手改 wide（≥1280px）桌面既有规则

### `compact`（<560px，含 Android WebView）

- [ ] 列表是**卡片**形态，且不提供形态切换钮
- [ ] 写弹窗全屏，header/footer 吃 safe-area
- [ ] 主操作 ≥44px；输入 ≥16px（防 iOS 自动缩放）
- [ ] 内容不被底栏挡住（内容底垫）
- [ ] 不在顶栏堆语言/主题/退出
- [ ] 超窄屏（≤380px）需要收紧时用 `isNarrow` / `.bp-*-on-narrow`，不写裸 380px
- [ ] 页面标题与 `meta.title` 绑同一个值
- [ ] 标题与当前页面一致；无标题弹层继承打开前标题
- [ ] 返回只作用最上层（已接 BackDispatcher 的页面自动满足）
- [ ] 连续加载：筛选变化调 `resetQuery()`，不是 `loadMore()`
- [ ] 列表**未同时**挂 `use-list-sentinel` 与 `ContinuousListController`
- [ ] 脏表单返回被拒时**留在原地**，不跳背景路由

### `medium` / `expanded` / `wide`

- [ ] 默认表格
- [ ] 列表页可见表格/卡片切换
- [ ] 对话框居中，非全屏
- [ ] 无底栏
- [ ] `wide`：侧栏与顶栏形态与改动前一致（红线）

## 3. 明确禁止

1. 为手机重写一套路由或 `Mobile*.vue` 页面副本。
2. 用 `isMobile = width < 768` 或 User-Agent 分支替代四档。
3. 改 wide 桌面的表格密度、侧栏宽度、对话框宽度「顺便适配」。
4. compact 顶栏塞语言 + 主题 + 用户 + 帮助。
5. 底栏超过 5 席或做双层 Tab。
6. 在原生层做第二套业务逻辑、存 Provider Key、做第二套登录 UI。
7. 卡片模式绕过字段脱敏或 RBAC 隐藏规则。
8. 新增断点魔法数或范围语法媒体查询。
9. 把 Provider API Key 放进文档、Git、`VITE_*` 变量、原生包或客户端模型配置。
10. 用 Web Worker / 后台定时器宣称任意任务永久保活，或后台静默开麦。
11. 把本地识别结果直接当财务事实，或另造第二套权威解析体系。
12. 只换分页 UI 而仍用「下一页覆盖上一页数据」。
13. 请求失败时清空已加载行再报错。
14. 吸顶写死「顶栏 48 + Tab 40」。
15. 用两套页面栈/复制交互表头/背景事件穿透实现导航或专注模式。
16. 把 `pages.reset()` 放在请求**发出**而不是**成功**之后。
17. `position: fixed` 的贴底浮层只按 `--app-safe-bottom` 定位，不让开
    `--bottom-chrome-height`（层级再高也没用——它是**主动钻到**底栏底下）。
    2026-10-06 实测三处：`MeetingDetailView .speakers-btn` 整颗按钮 100% 被盖、
    `MeetingMicDock .mic` 75% 被盖、`VaultEntryView .toast` 下沿被压。
18. 用裸数字手工复刻 `--bottomnav-height`（`bottom: 80px`）。这是
    「同一件事两处写法」，底栏一加高就静默失效。

## 4. 工程门禁

| 门 | 守什么 |
| --- | --- |
| `src/styles/__tests__/breakpoint-mirror.test.mjs` | 断点 CSS/JS 双镜像 + 无第三套阶梯 |
| `src/styles/__tests__/z-index-ladder.test.mjs` | 层级阶梯唯一权威：token 必须已定义、fallback 不得与 token 冲突、裸数字必须登记 |
| `src/styles/__tests__/bottom-chrome-gate.test.mjs` | 底部固定浮层必须让开 `--bottom-chrome-height`（否则被底栏盖住，与层级无关） |
| `src/lib/shell/__tests__/*.test.mjs` | 导航上下文 / 标题 / 返回 / 连续加载 / 吸顶 / 专注 / 能力 / 接线 |
| `npm run typecheck` | `vue-tsc` 全清 |
| `npm run test:all` | 全量 + **执行普查**（孤儿测试会让门禁红） |
| `npm run gates` | `gates.json` 名单，顺序执行、失败即停 |
| `node scripts/build-mobile.mjs android dev` | 构建 + **产物身份自检** |

## 5. 已知留白

这些是**规范承认**、待后续收的，不是本专题没写清：

- 吸顶 `dockCoordinator` 与专注 `focusWorkspace` **尚未接入任何真实页面**（仓内确无落点）
- `EmailInboxView.showLocal(replace)` 的 `replace` 参数已无语义（07 §2.9），
  保留只为不改调用点，勿以为它控制整表/合并重读
- 返回钮**可见性**仍按 `meta.canGoBack`（语义已用 `affordance()`）
- 顶栏三点更多图标统一、账户 Sheet 化
- 浏览器 Back 与覆盖层的原子协调（同 URL 临时 history 标记）
- Android 预测性返回四阶段
- `pluginAvailable` 的真实实现（当前保守报 `false`）
- 能力协商的 scope 接线（登出/换账号调 `runtime.setScope()`）
- 真机 30min 后台保活、Perfetto trace、OEM 后台策略适配

新需求不要在留白页上再叠第三种布局；要么接入上表的模块，要么显式降级。
