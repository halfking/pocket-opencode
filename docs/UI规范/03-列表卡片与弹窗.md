# 03 — 列表、卡片与弹窗

> 现行约束。连续加载部分已实现于 `lib/shell/continuousList.ts`，但**尚未接入页面**。

## 1. 两个独立维度

| 维度 | 取值 | 谁决定 |
| --- | --- | --- |
| 布局模式 | `cards` / `table` | 用户可切换；`compact` **强制** `cards` |
| 加载方式 | `continuous` / `paged` | 形态与页面性质；`compact` + 壳内倾向 `continuous` |

**不要用一个开关同时控制两者。** 平板上可以是 `table` 布局 + `continuous` 加载。

## 2. 列表布局

| 档位 | 列表形态 |
| --- | --- |
| `compact` | **强制卡片**，不提供切换钮 |
| `medium` / `expanded` / `wide` | 默认表格，可切卡片 |

卡片模式**不得**绕过字段脱敏或 RBAC 隐藏规则。

## 3. 连续加载（Hyper）

完整契约见 [07-Hyper滚动与专注](./07-Hyper滚动与专注.md) §2。接线时注意：

1. 页面把 `sentinel` 元素与**真实滚动宿主**（`AppLayout` 的 `<main>` 或页面自管
   容器）交给 `connectSentinel(el, root)`。`root` 必须是 sentinel 的祖先。
2. 筛选/月/项目/排序变化调 `resetQuery()`（**不是** `loadMore()`）。
3. 换账号/权限变化调 `invalidateScope()`。
4. `onActivated` 调 `resume()`，`onDeactivated` / `onUnmounted` 调 `pause()` /
   `disconnect()`。
5. 无 `IntersectionObserver` 时按 `needsManualLoad` 渲染「继续加载」按钮。
6. `shouldVirtualize` 为真时进入虚拟化或窗口缓存（裁剪旧页并记 anchor）。

### 3.1 迁移一页要改的四处（`MeetingListView` 为样板）

1. **import**：删 `useListSentinel`，加 `useContinuousList`。
2. **数据源**：`meetings` 换成适配层的 `rows`；`loadMore`/首屏 `load` 换成
   `resetQuery()`。offset 型后端在 `fetchPage` 里换算 `offset = (page-1)*pageSize`。
3. **哨兵**：`ref="moreEl"` → `ref="sentinelRef"`。
4. **失败/更多状态**：底部从纯文本改为**可点**的显式入口——
   `status==='failed'` → 「加载失败，点击重试」`retry()`；`hasMore` → 「加载更多」
   `loadMore()`。旧实现失败后停在半截且**没有任何重试入口**。

`fetchPage` 内仍要捕获页面特有错误（会议页的 `LocalDB 未初始化`），
那是页面语义，不该被通用失败态吞掉。

## 4. 弹窗

| 档位 | 写操作弹窗 |
| --- | --- |
| `compact` | **全屏**，header/footer 吃 safe-area |
| `medium` 及以上 | 居中对话框，非全屏 |

规则：

- 弹窗全屏时主操作 ≥44px、输入 ≥16px（防 iOS 自动缩放）。
- compact 下内容不被底栏挡住（内容底垫）。
- 卡片不新增固定 px 的裸 `el-dialog` 宽度。
- 弹窗有未保存数据时必须注册 `beforeClose`；返回被拒时**留在原地**，
  不跳背景路由（见 [06](./06-Hyper导航上下文.md) §5）。
- 弹窗若需要**无标题**（例如确认框），标题会自动继承打开前的有效标题 ——
  这是期望行为，不是缺陷。

## 5. 数据状态（首次/刷新/追加/未知写结果要分开）

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 骨架屏（复用统一 `Skeleton` 组件） |
| 刷新 | 保留旧行 + 刷新指示；**失败保留旧内容与筛选**，提示重试与更新时间 |
| 追加 | 底部「加载中」；失败显示「加载失败，点击重试」，保留已加载行 |
| 耗尽 | 「已全部加载 N 条」，不再观察 |
| 写操作结果未知 | 单独提示，**不得**当作失败静默重试 |

项目 / 权限代次改变后，旧响应无权回写（见 [07](./07-Hyper滚动与专注.md) §2.1）。

## 6. 禁止事项

1. 在 `compact` 档提供列表形态切换钮。
2. 卡片模式绕过脱敏 / RBAC。
3. 请求失败时清空已加载行再报错。
4. 筛选变化后仍用 `loadMore()` 追加而不提升代次。
5. 同一列表同时挂 `use-list-sentinel` 与 `ContinuousListController`。
