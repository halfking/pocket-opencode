# Cicada Phase A 手动测试指南

> **目标**: 在真机上验证实时字幕与翻译功能的完整性和性能  
> **更新时间**: 2026-01-09  
> **测试设备**: Xiaomi 2411DRN47C (Android 16)

---

## 测试前准备

### 1. 环境检查

```bash
# 1.1 确认真机已连接
adb devices -l

# 应该看到类似输出：
# 4c308e2e               device product:... model:2411DRN47C

# 1.2 确认后端服务运行
curl http://localhost:8080/health

# 1.3 确认 APK 已构建
ls -lh frontend/android/app/build/outputs/apk/debug/app-debug.apk
```

### 2. 安装应用

```bash
# 方式一：使用 adb 直接安装
adb -s 4c308e2e install -r frontend/android/app/build/outputs/apk/debug/app-debug.apk

# 方式二：如果需要重新构建
cd frontend
npm run build:fast
npx cap sync android
cd android
./gradlew assembleDebug
adb -s 4c308e2e install -r app/build/outputs/apk/debug/app-debug.apk
```

### 3. 启动应用

```bash
# 启动应用
adb -s 4c308e2e shell am start -n com.kaixuan.opencode.pocket/.MainActivity

# 查看日志（可选，用于调试）
adb -s 4c308e2e logcat | grep -E "SystemAudio|LiveSubtitle|Cicada"
```

## Phase A 测试项目

### ✅ 测试 1: 字幕悬浮窗基础功能

**步骤**:
1. 登录应用
2. 导航至"会议"页面
3. 创建或进入一个会议
4. 点击"开始录音"按钮
5. 说一些话（中文或英文）

**预期结果**:
- ✅ 录音开始后，字幕悬浮窗自动出现
- ✅ 悬浮窗位于屏幕上方或用户上次设置的位置
- ✅ 说话内容实时转写并显示在悬浮窗中
- ✅ 悬浮窗保持在所有内容之上（置顶）

**性能指标**:
- 转写延迟: < 1s
- 字幕更新流畅，无明显卡顿

**失败情况记录**:
- [ ] 悬浮窗未出现
- [ ] 悬浮窗出现但没有内容
- [ ] 转写延迟超过 2s
- [ ] 悬浮窗被其他元素遮挡

---

### ✅ 测试 2: 拖拽定位功能

**步骤**:
1. 在录音状态下，字幕悬浮窗已显示
2. 用手指长按悬浮窗
3. 拖动到屏幕的不同位置（上、下、左、右）
4. 释放手指

**预期结果**:
- ✅ 悬浮窗跟随手指移动
- ✅ 移动过程流畅，无延迟
- ✅ 释放后悬浮窗停留在新位置
- ✅ 位置信息被保存（重新进入会议时保持）

**性能指标**:
- 拖拽响应时间: < 16ms (60fps)
- 释放后稳定，无回弹或抖动

**失败情况记录**:
- [ ] 无法拖动
- [ ] 拖动时有明显延迟
- [ ] 释放后位置不正确
- [ ] 位置未保存

**预期结果**:
- ✅ 找到导出入口
- ✅ SRT 格式选项可见

- ✅ 内容完整，包含所有转写的句子

## 附录：常见问题排查

### 问题 1: 字幕悬浮窗不显示
**可能原因**:
- LiveSubtitleOverlay 组件未集成到 App.vue
- liveSubtitleIntegration 未初始化
- 录音状态未正确触发

**排查步骤**:
```bash
# 1. 检查日志
adb logcat | grep LiveSubtitle

# 2. 验证组件是否存在
# 查看 frontend/src/App.vue 是否包含 LiveSubtitleOverlay
```

### 问题 2: 翻译功能无响应
**可能原因**:
- 后端翻译路由未注册
- 网络连接问题
- API 端点配置错误

**排查步骤**:
```bash
# 1. 测试后端翻译 API
curl -X POST http://localhost:8080/api/meetings/translate \
  -H "Content-Type: application/json" \
  -d '{"text":"你好","targetLang":"en"}'

# 2. 检查网络请求日志
adb logcat | grep "translate"
```

### 问题 3: 导出功能失败
**可能原因**:
- 文件权限问题
- 存储空间不足
- 导出逻辑未实现

**排查步骤**:
```bash
# 1. 检查存储权限
adb shell dumpsys package com.kaixuan.opencode.pocket | grep permission

# 2. 检查存储空间
adb shell df -h
```
