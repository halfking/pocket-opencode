## 三、怎么跑真实数据库

完整步骤见 [如何验证真实数据库.md](如何验证真实数据库.md)。最短路径：

```powershell
# 1) 起一个能建 schema 的库（不要指向生产库）
docker run --rm -e POSTGRES_PASSWORD=pw -p 5432:5432 postgres:16

# 2) 跑全量集成测试
$env:POCKET_TEST_POSTGRES_DSN = "postgres://postgres:pw@localhost:5432/postgres?sslmode=disable"
cd backend
go test ./...

# 3) 确认真的跑了（而不是 SKIP）
go test ./... -v 2>&1 | Select-String "SKIP|PASS|FAIL"
```

无 DSN 时测试是 **SKIP 而非 PASS**——刻意如此，不产生假信号。

关掉 A7 还需要：起后端（`POCKET_POSTGRES_DSN` + `POCKET_HTTP_PORT`），
前端 `VITE_API_PROXY` 指过去，登录后打开 `/study` 与 `/tasks`。

## 五、给下一个接手的人

1. **别把 SKIP 当 PASS。** 门控测试无 DSN 时 SKIP，这是刻意的。
2. **别用「通配注册 + 鉴权前置」探测路由存在性。** 任何子路径都返回 401，
   只有负对照（不存在的路径返回 404）才有判别力。见
   [server-bin evidence](evidence/2026-09-30-server-binary-route-verification.md) §2。
3. **别把收集规则捞到的字符串都当图标名。** `starred` 是状态比较值、`name` 是变量名。
   判据是「上游完整字体里能不能合成」。
4. **新增动态图标先登记 `src/constants/icons.ts`**，构建脚本与两个门禁都从它读，
   不要往 `FALLBACK` 里手工追加——两份清单迟早漂移。
5. **`gofmt` 只对自己新建/修改的文件做。** 仓库有大量既有未格式化文件
   （`internal/server` 整片都是），全量格式化会制造一个巨大的无关 diff。
